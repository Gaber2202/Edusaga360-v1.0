Summary

This release delivers Phase 0 programme documentation (reconciliation audit, access checklist, branch assessment, CI guard for auth metadata) and Phase 1 application changes spanning atomic GL invoice posting, RLS claim remediation, fee-category tax matrix, SADAD tenant discriminator, jurisdiction-aware canteen receipts, and a staging migration pipeline. Also includes Prod hotfixes for parent-portal API proxy and TypeScript route param casts.

Phase 1 — What's New

P1-A

Auth Metadata Sync

Enhanced syncAuthMetadata.ts with dry-run summary, ghost detection, and production write guard. Runbook and dry-run report included (0 ghosts, 6 orphan privileged keys).

P1-B

Atomic GL Invoice Posting

create_invoice_with_journal Postgres RPC seeds chart of accounts and posts journal entries atomically. Billing route wired to RPC with ZATCA chain retry on fork.

P1-B CN

Credit Note VAT Reversal

Credit notes now reverse VAT through account 24 and store non-zero vat_amount on the credit note document.

P1-C

RLS Claim Remediation

Migration remediates legacy request.jwt.claims patterns to canonical auth.jwt() → app_metadata → tenant_id via auth_tenant_id().

P1-D

Money-Path Fixes

#185 residual-to-last-line rounding, #186 preview applies discounts, #187 effective date filtering, #190 SADAD tenant discriminator with unique index.

P1-E

Fee-Category Tax Matrix

SA / AE / QA fee-category → VAT treatment matrix with ADR-002 fail-closed errors. Bulk activation gate blocks unmapped categories.

P1-F

De-Saudization

SAR hardcodes removed from canteen receipts (jurisdiction-aware currencyCode). ContractTemplates, CommandPalette, and YamenAI copy updated.

P1-G

Migration Pipeline

applyMigrations.mjs and verifyMigrations.mjs scripts plus staging workflow job for verify-then-apply with health check.
