Summary

This patch replaces hard-coded role lists with a 26-role system catalogue (backend seed + GET /api/roles), refreshes the HR Manager and Payroll dashboards with KPI hero layouts, fixes the July attendance→payroll API drift (missing tables/columns), keeps employee PII readable after save, and restores legacy createJournalEntry posting for finance flows.

Features & fixes

Roles & access control

  • New /api/roles CRUD with system-role protection and tenant-scoped custom roles
  • appRoles.ts catalogue synced with sidebar module keys and action permissions
  • User Management & Role Management pages consume live catalogue (Arabic/English labels)
  • Sidebar navigation filtered by role module access from API

HR & Payroll UI

  • HR Manager Dashboard: hero, workforce mix, priority actions, demo-tenant banner
  • Payroll Dashboard: KPI strip, period-aware pay-run list, improved run details
  • Employees page layout aligned with new HR metrics helpers

Payroll engine

  • Attendance rows paginated (1k pages) so 10k-employee months are not truncated
  • Attendance load failures now fail loudly instead of zeroing deductions
  • Graceful fallback when attendance_policies table is absent
  • POST /api/functions/createJournalEntry compatibility route for GL posting

Build fix

  • Removed stray brace in WorkforcePlanning.jsx (Vercel build blocker)
