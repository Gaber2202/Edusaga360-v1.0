# EduSaga 360 — User Guide

## 1. School Registration

1. Go to **edusaga360.com/register**
2. Fill in: First Name, Last Name, School Name, Email, Phone, City, School Type, Estimated Students
3. Click **Submit Registration** — you'll see a confirmation page
4. EduSaga team receives a notification email at info@edusaga360.com
5. Within 24 hours you'll receive either:
   - **Approval email** with an onboarding link
   - **Denial email** with a reason

## 2. Onboarding Wizard (After Approval)

1. Click the onboarding link in your welcome email (valid for 48 hours)
2. Complete 4 steps:
   - **Set Password** — create your login password
   - **School Logo** — upload your school logo (optional)
   - **Academic Year** — set start month, number of grades
   - **Language** — choose default language (Arabic or English)
3. On completion → you're redirected to your Dashboard

## 3. School Admin — Managing Your School

### Dashboard
- View KPIs: total students, employees, attendance rate, revenue
- Recent activity feed shows latest actions
- Quick links to common tasks

### Admissions
- Create new student applications
- Review and approve/reject applications
- Track enrollment pipeline

### Students
- View all students with search and filters
- Add new students with full profile (name, grade, section, parent info)
- Track attendance, grades, and enrollment status

### HR & Employees
- Manage employee profiles (personal info, documents, contracts)
- Track leave requests and approve/deny
- Monitor attendance records
- Process payroll through pay run workflow

### Payroll
- Create monthly pay runs
- Configure salary structures
- Process GOSI contributions
- Generate payslips

### Fees & Invoices
- Set up fee structures per grade/term
- Generate bulk invoices
- Track payments and outstanding balances
- View financial summaries

### Finance
- Record journal entries
- Manage budgets
- Track expense reports
- View financial dashboards

### Procurement
- Create purchase requisitions
- Approve and convert to purchase orders
- Manage vendor relationships
- Track deliveries

### Assets
- Register school assets
- Track depreciation
- Schedule maintenance
- Generate asset reports

### Communications
- Send announcements to parents/staff
- Manage messaging templates
- WhatsApp integration support

### Reports
- Executive dashboard with KPIs
- Financial reports (P&L, balance sheet)
- Student reports (enrollment, attendance)
- HR reports (headcount, turnover)

### Subscription
- View your current plan and usage (users, students, employees)
- Request plan upgrade or downgrade
- Request additional user seats
- All changes require EduSaga team approval (processed within 24 hours)

### Yamen AI
- **HR Mode** (for admins): Ask about employee data, leave balances, attendance patterns, compliance risks
- **Employee Mode** (for staff/teachers): Ask about your own leave balance, attendance, payslip

### Settings
- Manage users and role assignments
- View audit logs (admin/IT only)
- Configure school preferences

## 4. Teacher Access

Teachers can access:
- Dashboard (limited view)
- Students (their classes only)
- Attendance (mark attendance for their classes)
- Yamen AI (employee self-service mode)
- Communications (view announcements)

Teachers **cannot** access: HR, Payroll, Finance, Procurement, Assets, Settings, Subscription

## 5. Parent Portal

### Accessing the Parent Portal
1. Go to **parentportal.edusaga360.com**
2. Login with the email and password provided by your school
3. You'll see a dashboard with your children's information

### Available Features
- **Student Progress** — View grades and academic performance for each child
- **Attendance** — Check daily attendance records
- **Fees** — View pending and paid fees, payment history
- **Announcements** — Read school announcements
- **Messaging** — Send messages to teachers

Parents **cannot**: access other parents' data, view school staff information, access any admin features

## 6. Super Admin Portal (EduSaga Internal)

### Accessing the Admin Portal
1. Go to **admin.edusaga360.com**
2. Login with your EduSaga team credentials
3. Only `edusaga_superadmin` and `edusaga_staff` roles have access

### Tenant Management
- View all registered schools
- Activate, suspend, or delete tenants
- View tenant details and usage metrics

### Subscription Management
- View plan distribution across all tenants
- Review pending upgrade/downgrade requests
- Approve or deny plan changes with admin notes
- Track request history

### Platform Analytics
- Platform-wide usage metrics
- Active users, tenant counts
- Revenue tracking

### Audit Logs
- Cross-tenant activity logs
- Filter by action type, user, date

### Email Templates
- Manage registration, approval, denial email templates

### Feature Flags
- Toggle features per tenant
- Control module access

## 7. Language Switching

All three portals support Arabic and English:
- Click the language toggle (globe icon) in the sidebar/header
- The entire UI switches direction (RTL for Arabic, LTR for English)
- Data labels, form fields, and navigation all translate
